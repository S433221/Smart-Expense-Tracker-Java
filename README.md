# 💰 Smart Expense Tracker - Java

A console-based personal finance tracker built for BCA Placement prep.

**Why this project?** To learn beyond To-Do - File Persistence + HashMap real-world use.

### 🚀 Features
- Add/View Expenses
- Monthly Report Category-wise using HashMap O(1)
- Split Expense with Friends (Splitwise clone logic)
- Data Persists in expenses.txt even after app closes

### 🛠️ Tech Stack & DSA
- Java, OOPs, ArrayList, HashMap
- File I/O for persistence

### ▶️ How to Run
javac Expense.java ExpenseManager.java Main.java
java Main
